# Red Flag or Green Light v1.1.0

## What's new

- **New question bank:** 81 questions across **Beginner**, **Everyday**, and **Expert**, plus an **All Levels** round that goes from easy to hard.
- **Two kinds of questions** in every round of 10: 🚩 / 🟢 spot the trap or the sound money move, and 🧠 know the basics. Results show how you did by topic.
- **Looks like a real app:** black launch screen with the big logo, new launcher icon, solid app bar, and About / Privacy / Credits panels.
- **Back button works:** asks before quitting a round, returns to the level picker from results, and asks before exiting.
- Still **100% offline**: no internet permission, no ads, no analytics, no accounts.

## Important: uninstall v1.0.0 first

This release is signed with a new key, so it can't install over v1.0.0. Uninstall the old app first. The app saves nothing, so nothing is lost.
